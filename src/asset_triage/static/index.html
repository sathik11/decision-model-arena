System One  /  decisions without generation

Not every decision
needs a sentence.

Every lane below runs on Foundry. Foundry holds the evidence, the policy, the orchestration, the tracing and the governance — that never changes. What changes is how the decision itself is produced: generated token by token, or returned directly by a typed decision model that Foundry calls. The arena runs both on the same evidence and shows what was fed in, what came back, and which tokens stopped being produced.

01Evidence

The incident.

02Model input

What is actually fed to Laya.

Laya and Jev are not prompted. They receive a state object plus a question contract: for each question a primitive type — choice score noul — an instruction, and the criteria that define each option. The criteria are semantic anchors, not few-shot examples. The model encodes the state against each question and reads the answer off a decision head.
